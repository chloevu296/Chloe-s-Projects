# Mercury Co-operative Data Analytics Project
## Overview

This project was completed as part of Macquarie University's PACE (Participate and Connect for Experience) Industry Program in collaboration with Mercury Co-operative.

The project aimed to transform complex co-operative and socioeconomic data into interactive Power BI dashboards that support data-driven decision-making for different stakeholder groups.

---

## Business Problem

Mercury Co-operative required an interactive solution to better understand Australia's co-operative landscape and communicate insights to different users through accessible and engaging visualisations.

The project focused on combining multiple public datasets with co-operative information to identify patterns, opportunities and support strategic planning.

---

## My Contributions

- Developed stakeholder-specific non-trivial business questions that shaped the analytical direction, dataset selection and dashboard design for the project.
- Designed three stakeholder personas and translated their decision-making needs into measurable analytical objectives.
- Integrated and analysed data from multiple sources to uncover insights on co-operatives, employment, innovation and housing.
- Built interactive Power BI dashboards that enabled stakeholders to explore data and support evidence-based decision-making.
- Interpreted findings and contributed strategic recommendations in the final report and client presentation.
